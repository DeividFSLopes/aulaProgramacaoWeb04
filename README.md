## 🐾 ONG Amigão

Este projeto foi desenvolvido como parte das atividades práticas de Programação Web, evoluindo a cada entrega com foco em HTML, CSS, JavaScript e Boas Práticas de Desenvolvimento Web.

---

## 🌍 Sobre o projeto

A ONG Amigão é uma organização fictícia sem fins lucrativos dedicada ao resgate, cuidado e adoção de animais abandonados.
O site apresenta informações sobre a ONG, seus projetos, formas de voluntariado e uma página de cadastro funcional com validações e integração Java.

---

## 📄 Páginas do site

index.html – Página inicial com informações sobre a ONG e formas de contato.

projeto.html – Apresenta os principais projetos e formas de doação.

cadastro.html – Formulário para cadastro de voluntários e doadores com validação de dados e integração com Java.

---


## 🧩 Estrutura de diretórios

As imagens utilizadas estão na pasta /imagens e os estilos estão em /css/style.css.

---

## 🛠️ Tecnologias utilizadas

HTML5 – Estrutura semântica e organizada

CSS3 – Layout responsivo e estilização moderna

JavaScript – Validação e formatação automática (como CPF e mensagens de erro)

Java (Servlets) – Integração de backend na Etapa 3

Git e GitHub – Controle de versão e versionamento semântico

--- 

## ♿ Acessibilidade (WCAG 2.1 Nível AA)

O site segue boas práticas de acessibilidade digital, incluindo:

Navegação completa por teclado

Contraste de cores adequado (mínimo 4.5:1)

Textos alternativos em imagens (alt="")

Versão com modo de alto contraste / modo escuro

Suporte a leitores de tela com marcações acessíveis

---

## 🧭 Versionamento (GitFlow)

O repositório segue o fluxo de versionamento GitFlow, com:

main – versão estável em produção

develop – versão de desenvolvimento

Branches de feature (feature/*), release (release/*) e hotfix (hotfix/*)

Commits semânticos e organizados

Histórico documentado e milestones definidos

---

Entrega II: Estilização completa com CSS3

Entrega III: Integração com Java e validação de formulário

Entrega IV: Acessibilidade, versionamento e deploy final
